# 功能详解

本文按「你会看到什么 → 怎么操作 → 背后怎么实现」介绍 Antigravity Pokémon Pets 的每一项功能。安装与卸载请看 [README](../README.md)，接口与数据结构请看 [architecture.md](architecture.md)。

---

## 1. 智能体伙伴：每个 AI 智能体一只宠物

在 Antigravity 里，每个正在工作的 AI 智能体都会配一只伙伴：

- **会话领队（👑 leadAgent）**：你直接对话的主智能体，或 Swarm 编队里的 `coordinator`。
- **子智能体（subagents）**：主智能体派出去干活的子代理、Swarm 成员。

伙伴会用动作实时反映智能体当前在做什么：

| 状态 | 伙伴表现 | 什么时候出现 |
| :--- | :--- | :--- |
| 💭 思考中 `thinking` | 歪头悬浮，头顶冒思考气泡 | 收到新消息、正在推理下一步 |
| ⚡ 工作中 `working` | 快速跳动，释放招式粒子 | 正在执行工具（读写文件、运行命令等） |
| 💤 休眠 `sleeping` | 蜷缩闭眼，飘出 `Zzz` | 等待中，或一轮对话结束一段时间后 |
| 🎉 庆祝 `celebrating` | 欢呼跳跃，爱心与星光 | 一轮对话刚刚顺利完成 |
| 😵 出错 `error` | 眩晕圈圈眼、汗滴 | 最近一步执行报错 |

伙伴形象按角色自动分配（例如领队、验收员、侦察员各有固定伙伴），其余智能体按名字稳定地映射到某一只，同一个智能体每次出现都是同一只。

## 2. 多项目会话列队

所有界面都按同一套规则排队，多个项目、多个会话同时运行时也不会混在一起：

1. **一个会话一排**：同一会话的智能体横向排成一排；多个会话就上下分成多排。
2. **按项目归组**：同一个工作区下的会话聚在同一个 `📁 项目名` 分组里。
3. **领队永远在最左边**：每排第 0 位固定是戴皇冠的 `👑 leadAgent`，后面依次是它的子智能体。
4. **闲置子智能体自动退场**：子智能体休眠超过 60 秒就从队列里移除，不会越积越多。
5. **领队保活**：只要这一排还有任何子智能体在干活，领队就不会被移除，哪怕它自己已经闲置很久。
6. **点领队看会话**：
   - **单击**领队：弹出金色气泡，显示 `💬 会话标题` 和 `📁 所属项目`。
   - **双击**领队：自动还原并置顶对应的 Antigravity 窗口，并切换到这个会话。

## 3. 桌面共享浮窗（Windows）

一个透明、始终置顶的桌面小窗，显示所有项目的伙伴队列：

- **全局只有一个**：无论开了多少个 Antigravity / Antigravity IDE 窗口，都共用这一个浮窗，不会重复弹出。
- **两种画风**：高清 3D 动图（Showdown 风格）和黑白世代像素风，可随时切换。
- **双环进度条**：每只伙伴身上有两个圈。外圈红色表示**已用上下文比例**，内圈绿色表示 **Prompt 缓存命中率**，一眼就能看出哪个智能体快塞满了、哪个缓存掉了。
- **常用操作**：换肤、点击穿透（鼠标可以穿过浮窗操作下面的窗口）、收起、关闭。
- **关掉后召回**：点 `[×]` 关闭后，本次 Antigravity 运行期间不会自动重弹（下次打开 Antigravity 2.0 时会重新自动出现）；想马上找回，重新运行 `start-pokemon-ide.ps1`，或在副屏 / 皮肤菜单里点「召唤浮窗」即可。
- **与 IDE 同启同停**：带 `-BindToIde` 启动时，Antigravity 打开浮窗就出现，Antigravity 关闭后浮窗自动退出（按 `Ctrl+R` 重载窗口不会误关）。
- **自检**：`pokemon-desktop-overlay.ps1 -SelfTest`（需加 `-STA`）可无界面检查列队规则与全部动图帧是否正常。

## 4. Antigravity 全界面皮肤

不只是编辑器配色，而是把 Antigravity 的**整个窗口**换成玻璃拟态风格：标题栏、对话气泡、代码块、输入框、滚动条和右侧面板都会变。

- **7 套配色**：`mewtwo`（默认）、`pikachu`、`gengar`、`charizard`、`umbreon`、`pokedex-light`、`rotom-light`。
- **任一处切换，全端同步**：在任意窗口切换配色后，其他窗口、浮窗与副屏会一起换。
- **同时支持两个客户端**：Antigravity IDE 和 Antigravity 2.0。
- **全局列队栏**：在客户端界面里也能看到项目 / 会话队列。
- **一键还原**：修改前会自动备份原文件（`*.pokemon-backup`），`-RestoreGlobalSkin` 可完整恢复。

## 5. Subagents 面板编队卡片

客户端右侧的 `Subagents` 面板会被升级成「随身编队」样式：

- 每个子智能体一张卡片，配上伙伴动图、属性色发光边框和能量条。
- 状态徽章：`⚡ WORKING`、`💭 THINKING`、`💤 SLEEP` 等。
- 只在原有界面上**叠加装饰**，不替换原生节点，点击展开等原有交互全部保留。

## 6. IDE 代码配色主题与侧边栏

`vscode-pokemon-theme/` 是一个 Antigravity IDE 扩展：

- 提供 6 套编辑器与工作台配色主题。
- IDE 启动时自动拉起状态桥与桌面浮窗。
- 侧边栏里有一个「项目分组 · 会话列队」实时面板，同样支持单击 / 双击领队。

## 7. Antigravity 2.0 副屏插件「桌宠乐园」

`plugin-bundle/pokemon-agent-pets/` 是 Antigravity 2.0 的插件，在右侧副屏打开「桌宠乐园」：

- 实时显示伙伴列队，支持单击 / 双击领队。
- 自带健康巡检：每 10 秒检查一次状态桥，发现没在运行会自动拉起。
- **随 app 自动弹出桌宠**：Antigravity 2.0 启动后，如果桌面浮窗没在运行就自动打开一次（防多开，不会出现第二个浮窗）；上次运行中点 `[×]` 留下的关闭标记会被忽略，本次运行中点 `[×]` 后不再自动弹出。不需要时把插件目录 `workspace-config.json` 里的 `autoShowDesktopPet` 改为 `false`（重新同步插件会保留这个设置）。
- 工具栏可切换皮肤包、打开网页舞台、召唤桌面浮窗。
- 用 `plugin-bundle/sync-plugin.ps1` 同步到本机插件目录后，在 Antigravity 的 **Customizations** 界面手动开启。

## 8. HTML5 网页舞台

`desktop-pet/overlay.html` 是浏览器版的大舞台，适合放在副屏上全屏观看：功能和桌面浮窗一致，可用 `start-pokemon-ide.ps1 -OpenWebStage` 打开。

## 9. 可替换的皮肤包

伙伴长什么样完全由「皮肤包」决定，可以自己做：

- **皮肤包内容**：一个 `pack.json` 描述每只伙伴的名字、动图、稀有度与闪光外观，加上对应的图片文件。格式参考 [packs/critters/pack.json](../packs/critters/pack.json)。
- **默认包「像素小伙伴」**：仓库自带 7 只完全由代码绘制的原创像素伙伴（CC0，可随意使用），可用 `node tools/build-critters-pack.mjs` 重新生成。
- **宝可梦包**：仓库附带 7 只宝可梦的精灵素材，**仅限个人非商业使用**（见 [NOTICE.md](../NOTICE.md)）。用 `node tools/export-pokemon-pack.mjs` 生成本机私有包；`node tools/build-allgen-pokemon-pack.mjs` 可联网下载全世代精灵。
- **查找顺序**：仓库 `packs/` → 本机 `~/.gemini/antigravity/pet-packs/` → 环境变量 `POKEMON_PACK_DIRS` 指定的目录；同名时后者覆盖前者。
- **切换**：在舞台「设置 → 皮肤包」或副屏工具栏随时切换。

## 10. 本地状态桥

以上所有界面的数据都来自一个本地小服务 `bridge/agent-monitor.mjs`：

- **只在本机运行**：监听 `127.0.0.1:17580`，不对外开放，也不会把任何数据上传。
- **只读**：读取 Antigravity 写在本机的会话摘要、对话轨迹日志、Swarm 成员信息，汇总成「项目 → 会话 → 智能体」的队列。
- **实时**：通过 SSE 推送变化，界面延迟通常在 0.5 秒以内。
- **无需 npm 包**：需要 Node.js v24+，但只用 Node.js 自带功能，不需要 `npm install` 任何包；后台进程静默启动，不弹命令行窗口。
- **可选生命周期钩子**：`bridge/hook-handler.mjs` 可以接收 Antigravity 的钩子事件，让状态更新更及时；它不会阻塞 AI 的正常运行。

常用检查命令：

```powershell
Invoke-RestMethod http://127.0.0.1:17580/health       # 状态桥是否在运行
Invoke-RestMethod http://127.0.0.1:17580/api/agents   # 当前的项目 / 会话队列
```
